# 検索競合分析

調査日：2026-10-16（日本時間）。対象：採用動画制作・採用YouTube運用代行。目的：質の高い問い合わせ、商談、受注に寄与する判断材料を選ぶ。これは観測に基づく戦略提案であり、競合の実績を第三者として保証するものではない。

## 結論

KYUTEが先に整えるべきものは、会社比較・費用・発注条件からサービスへ進む導線と、密着動画の制作判断を説明できる一次情報である。「一気通貫」「資産」「採用成果」だけでは差がつかない。今回確認した競合も同種の訴求を使っている。自社メディアの経験を顧客の採用成果に置き換えず、何を制作し、どう使い、どこまで測定できたかを分けて示す。

## 矛盾・解釈・優先順位

1. **競合の価格幅は一致しない。** 撮影日数、動画形式、本数、企画、二次利用などが異なる。平均して「市場相場」を作らない。KYUTEの単価の有利不利は同じ要件の見積もりで検証する。
2. **高い再生数/制作本数は採用成功の証明ではない。** 競合の成果は各社記載であり、集計条件・採用母数・他施策の影響は未監査。KYUTEも同じ基準で扱う。
3. **検索スニペットと本文がずれる。** 記事タイトル/選数/更新日の差を順位変化と解釈せず、取得日と実本文を記録する。
4. **ページの充実とSEO成果は別。** 今回は構造を観測したが、競合の流入・CVR・受注を取得していない。戦略の確信度は「比較検討の判断材料を増やす：中〜高」「順位や受注増の幅：不明」。

| 優先度 | 選ぶ対応 | 判断の理由 | 検証 |
|---|---|---|---|
| P1 | 既存会社比較記事→作品/料金/サービスの接続を改善 | A/B層の判断を助け、同一KW記事の競合を増やさない | 記事別サービス遷移、資料請求、商談化 |
| P1 | 料金の適用条件・準備項目を一次情報で整理 | 低価格だけを訴求せず適合する相談を増やす | 商談前の同じ質問の減少、適合商談比率 |
| P1 | 自社メディアと顧客事例の区分を維持 | 現在の証拠を正確に使い信頼を保つ | 出典/許諾/期間レビュー |
| P2 | 撮影判断や運用判断を解説する専門コンテンツ | 同質の総論記事を増やすより独自性がある | 検索クエリと有効商談の一致 |
| 保留 | 汎用「動画制作」領域への大量記事展開 | ターゲットが広く、現在の証拠・制作能力を分散 | A/B層の検証後に判断 |
