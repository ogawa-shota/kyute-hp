# 実装・運用ロードマップ

基準日：2026-10-16 JST。目的は自然検索起点の適合問い合わせ→商談→受注。検索順位・DR・記事数は説明変数。以下の効果は予測・仮説であり、増加率の保証ではない。

## 選択

2つの既存サービスLPと、外注先・費用の比較意図を優先する。広い採用ノウハウを大量に増やすより、意思決定に必要な制作条件・実例・採用導線を示す。既存URLを維持し、密着動画の具体的な制作判断を一次情報として積み上げる。競合も「資産」「一気通貫」を使うため、それ自体を独自の強みとはしない。

## 直近1週間

1. PRの実装・監査証跡をレビュー。本番公開の承認後に公開し、正規URLとフォームを再確認する。
2. GSCで所有権・sitemap・主要3URLのGoogle選択canonical、手動対策を確認。過去90日/16か月の集計を取得する。
3. GA4の本番ID、拡張計測OFF、generate_leadの主要イベント指定を確認。実送信テストは通知発生を含め事前に承認する。
4. 会社比較記事の料金CTAと次に作る費用記事の一次情報を確定。既存記事を増殖させない。

## 直近1か月

- 最初の28日を計測基準にする。少数のCVだけで勝敗を決めず、LP遷移、資料成功、適合問い合わせ、商談化を一緒に見る。
- 費用・導入判断の2テーマを、公開可能な資料が揃った順に制作/レビュー。未確認の価格や顧客成果は公開しない。
- 週次HTTP監視の失敗を確認し、技術障害とアクセス制限を分離する。
- 関連性のある被リンク候補3件を選び、承認された宛先だけに連絡する。

## 直近3か月

- 成果が出た検索意図に関連する記事へ投資し、表示されるがCTRが低いページをリライトする。
- 事例の許諾を取って、制作物/採用成果を区別した導入事例を制作する。
- ページ別の商談・受注寄与を加え、検索流入増でも不適合問い合わせが増えるテーマは優先度を下げる。
- DRの数値目標を置かず、関連媒体からの引用・紹介流入・適合商談で被リンク施策を見直す。

## 実行しないこと

本番無断公開、料金や保証の変更、不要なURL移転、記事数を目的にした量産、リンク購入/大量相互リンク、無根拠な被リンク否認、顧客の実績の創作、検索量/KD/DRの推定値捏造。

## 判定基準

技術修正は公開後HTTPで即時確認する。検索成果は2–4週でクロール/登録状態、4–8週でクエリと遷移、8–12週で商談寄与を確認する。季節性・新規記事・指名検索・営業施策を注記し、前後比較を因果効果と断定しない。流入が少ない場合は集計期間を延長する。
