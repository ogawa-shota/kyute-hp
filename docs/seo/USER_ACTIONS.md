## P1：GA4の任意設定と送信確認（30–45分）

- 目的：無料標準GA4で検索流入→LP→資料請求完了を追う。現在VercelはHobbyのため、Vercelカスタムイベント集計は未稼働として扱う。
- 手順：既存のGA4プロパティ/データストリームをまず確認。なければ本人が作成し、サイトURLを`https://www.kyute.jp`、タイムゾーンを日本に設定。管理画面の**拡張計測をOFF**にする（特に履歴遷移pageview、フォーム、外部リンク）。別のGTM/GAタグがないことを確認。詳細は`MEASUREMENT_PLAN.md`。
- 設定値：Vercelの対象プロジェクト`kyute-hp`のProduction環境変数へ`NEXT_PUBLIC_GA_MEASUREMENT_ID=G-...`を登録。これは公開IDで秘密キーではない。API secretは不要。設定を反映する再ビルド/公開は公開承認後にCodexが行う。
- 通知/同意：既存サイトのプライバシー通知と、自社の同意運用・対象地域に照らして計測導入条件を確認する。未確認ならIDを空欄にして無効を維持する。
- 共有：設定完了、公開してよいか、DebugView/Realtimesで`page_view`と`generate_lead`が1回ずつ見えるか。アカウント認証情報やAPI secretは共有しない。
- 未完了の影響：GA4は読み込まれず、成功イベントの集計先がない。コード実装だけを計測開始と呼ばない。
- 先行済み：個人情報/query/hashを送らないイベント実装、未設定時の無効化、重複防止・成功時のみ送信のテスト。
- 外部通知を伴うテスト：実資料請求はメール/Slack通知を発生させる。テスト先と実行を明示承認してから行う。現時点のテストはmockのみ。
