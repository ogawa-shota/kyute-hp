# 外部評価・被リンク獲得戦略

作成：2026-10-16。目的：採用課題を持つ企業に見つけてもらい、確認可能な専門情報への引用・紹介から質の高い相談を増やす。DRは補助指標とし、リンク数/DRだけを目的にしない。候補調査・企画・文案を作成済み。外部連絡、申し込み、課金、公開は未実施。

## 現在値と解釈

2026-10-16、Ahrefs無料Website Authority Checkerの実ブラウザ表示で、kyute.jpは **DR 0、Backlinks 717、Linking websites 378**。dofollowはリンクの15%、リンク元サイトの14%と表示された。証跡：[取得画面](evidence/ahrefs-kyute-20261016.jpg)。正確な取得スコープと追加実測は [BASELINE_METRICS.md](BASELINE_METRICS.md) を正本とする。比率は丸め値であり、正確なdofollow/nofollow件数を逆算しない。

[Ahrefsの公式定義](https://ahrefs.com/seo/glossary/domain-rating)によるDRは、同社独自のリンクプロファイル指標である。Googleの評価スコアや売上、専門性そのものではない。他社のDA/Authority Scoreと置き換えない。

### 被リンクサンプルで分かったこと

Ahrefs Backlink Checkerの「サブドメインを含むドメイン、1ドメイン1リンク」表示サンプルは、採用/HRと関係の薄いと思われる`.shop`ドメイン、SEO・リンク・PBNに関する文言を含むページが目立った。確認したのはツールの表示/リンク先文字列であり、リンク元ページを全件精査したものではない。証跡：[JSON](evidence/ahrefs-backlinks-20261016.json)・[画面](evidence/ahrefs-backlinks-20261016.jpg)。

この観測だけから、購入、攻撃、Googleのペナルティ、DR 0の原因を断定しない。378サイト全体の品質構成を、このサンプル割合から推定することもしない。取得元ツールのデータベースとGoogleが評価するリンク集合は一致するとは限らない。

初動はGSCの「手動による対策」「セキュリティの問題」「リンク」と、利用可能な被リンク一覧の確認である。出現日・リンク先・アンカー・rel属性・実ページの内容を点検し、自然な紹介と無関係な参照を分ける。**一括否認は行わない。** Googleは多くのサイトで否認ツールを必要としないと説明している。必要性が認められる場合だけ、所有者と根拠を確認して個別判断する。[Googleの否認ガイダンス](https://support.google.com/webmasters/answer/2648487?hl=ja)。

## 戦略の選択

1. 公開できる制作判断・事例・比較用情報を、安定したURLにまとめる。
2. 読者の課題が近い媒体や、実際に関わった企業に、情報として有用な場合に紹介してもらう。
3. 紹介流入のサービス閲覧・相談・商談化を確かめ、引用と営業への貢献がある企画を続ける。

最初の重点は既存関係先の事例紹介、専門媒体への企画、少人数の共同イベント。大規模アンケートやツール開発は、編集者・顧客の反応を確認してから行う。制作予算を薄い調査やリンク数確保へ分散しない。

## 独自調査の準備案

研究問い：採用担当者は、動画のどの利用場面と採用成果を結びつけて測っているか。対象候補：採用に動画を利用した企業の担当者。募集方法が自社関係者中心なら、その偏りを記載し「日本企業全体」を代表する調査と呼ばない。

設問案：利用する採用段階／作った動画の形式／発注前に決めた項目／測っている指標／制作後に困ったこと。設問全文、募集経路、回答期間、有効回答数、重複除去、欠損処理、匿名化方法を先に定義する。数値は回答取得後に集計し、グラフ化は分母と条件が揃った項目だけにする。必要サンプル数や統計的な代表性は調査目的と募集法が固まるまで未設定。

## 運用・KPI・中止条件

候補台帳は `候補URL / 読者適合 / 企画 / 素材 / 許諾 / 送信承認 / 接触日 / 返答 / 掲載URL / rel属性 / referral / 有効相談 / 商談 / 備考` を持つ。公開連絡先以外の個人情報は適切な非公開管理へ置く。

月次で、関連性のある紹介元、引用されたページ、紹介流入、サービス遷移、有効相談、商談化を確認する。GSC/Ahrefsのリンク数はデータソース別に記録し、両者を足さない。DRは月1回同じツール/スコープで観測するが、契約KPIにしない。

営業広告しか受け付けない媒体は、独立したリード獲得費用として検討し、無料の編集掲載として数えない。資料が宣伝だけになった、公開許諾が得られない、紹介読者が採用企業と合わない場合は企画を見直す。返事がない相手への反復連絡を自動化しない。
